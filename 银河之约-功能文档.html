01产品概览

银河之约由两层组成：公开首页是所有访客都能看的品牌落地页，用星图、地球、纪念日、照片墙演示「这个产品长什么样」；私密空间是登录后两个人的真实空间，存放日记、照片、私信与全部纪念。

产品定位情侣纪念与日常记录工具，强调「只给两个人看」的私密感和仪式感
访问方式浏览器打开网址即可；可「添加到主屏幕」当 App 用，断网仍能看已缓存的页面
账号形态两个独立账号 + 一枚 6 位配对码，配对后共享同一个空间
数据形态文字、照片、文件、语音、语音/视频通话，全部围绕「两个人」组织
存储方式本地模式（只存本机浏览器）或云端模式（Supabase，两台设备实时同步）
演示数据首页所有内容均为演示数据，不含真实个人信息；真实数据只存在于私密空间
一句话理解：首页是「橱窗」，情侣空间是「家」。装修橱窗不影响家里的东西；家里有什么，只有你们两个人知道。

02访客首页

首页按浏览顺序分为：开屏加载 → 品牌大标题与地球 → 星图 → 纪念日 → 日记 → 照片墙 → 私语与相见 → 留言板。底部有胶囊导航，滚动时自动高亮当前区块。

2.1 视觉与动效

真实地球用三张贴图叠加渲染：白天地表、云层、城市夜灯；带昼夜渐变、大气散射、晨昏线与海面微光。素材缺失时自动退回程序化地球，不会黑屏
星空背景粒子星场 + 银河光带缓慢旋转 + 低透明度星座线稿（随滚动轻微视差）
点击星空在空白处点击会落下一颗发光星，自动与上一颗连线；约 9 秒后用 6 秒渐隐消散，左下角可一键清除（不做持久保存）
氛围细节胶片颗粒、暗角、鼠标光晕（触屏设备自动关闭）、区块入场动画
开屏动画启动时有一段加载动画；网址加 ?dev 可跳过（调试用）

2.2 五个内容区块

星图（演示）赤道坐标系星图：赤经赤纬刻度、银河带、背景星场、两座星座连线与代表星准星、两星角距标注。带 DEMO 角标，示意「把两个人的星座连成一张图」
纪念日（演示）三列卡片，自动判断「已过去 / 倒计时 / 就是今天」；桌面三列、手机两列自适应
日记（演示）两篇示例日记卡片，展示心情标记、图文混排、私密可见等卖点
照片墙（演示）编辑式拼贴排版，点击可放大预览，悬停显示说明文字
私语与相见展示「私信 + 通话」能力的引导区块，把访客引向注册

2.3 留言板与建议

  • 留言板：终端风格，访客留言保存在当前设备的 localStorage，只有这台电脑/手机能看到，用于体验交互。
  • 给作者的建议：表单提交后写入云端 lm_feedback 表，作者在 Supabase 后台查看，用于收集产品改进需求。

2.4 入口

首页提供两条进入路径：点击「开启属于我们的空间」按钮，或点击底部导航的「空间」。未登录时先看到登录/注册弹窗。

03账号与配对

注册（第一个人）→创建空间，拿到配对码→把配对码发给 TA→注册（第二个人）→输入配对码加入→两人看到同一个空间
账号字段用户名、密码、昵称、星座、生日（昵称、星座、生日用于资料卡与纪念日日历）
密码存储服务端以 sha256(密码) 保存，不存明文；老账号首次登录成功后自动升级为 sha256
配对码6 位大写字符，创建空间时生成，可在「今日」页顶部和「我们」页查看
加入空间第二个人注册时选择「加入TA的空间」并填写配对码；也可注册后在空间内用配对码加入
解除配对「我们」页底部「解除配对」，需二次确认；解除后空间数据不再对彼此可见，账号保留
登录态保存在本机 localStorage，下次打开自动进入空间；点右上角「退出」可退出
一人一空间一个账号同一时间只属于一个空间；空间最多两人
演示 / 调试入口：网址后加 ?demo=1 会自动灌入一对演示情侣与几天示例记录并直接进入空间（仅本地模式生效），用于体验功能，不影响真实账号。

04空间七个页面

登录后进入全屏空间界面，顶栏固定：左侧是两人的名字与「在一起第 N 天」，中间是七个标签页，右侧是「写日记」「提醒」「退出」。

4.1 今日

  • 两个人的今天并排展示，谁写了、谁还没写一眼可见。
  • 未写的一侧显示「今天还没记录」的空状态提示。
  • 自己的那篇可以直接编辑或删除。

4.2 日记

写作规则不限篇数，同一天可写多篇；每次点「＋ 写日记」都新建一篇，改旧记录点卡片上的「编辑」
字段心情（10 种：晴朗 / 微风 / 多云 / 小雨 / 开心 / 想念 / 平静 / 激动 / 疲惫 / 治愈）、标题（可空）、正文
照片一篇最多 9 张；自动压缩到最长边 1280px、JPEG 质量 0.82；单张超过 20MB 会被跳过并提示
展示按日期倒序分组；两个人都写了的日子标记「❤ 都记录了」
权限只能编辑/删除自己的记录，不能改动对方的

4.3 照片

  • 自动汇总日记里所有照片，形成相册。
  • 按月份聚合：每个月一个分组标题，显示该月张数。
  • 点击任意一张可全屏预览。

4.4 足迹

时间线视角：两个人的所有记录按时间顺序串成一条光轨，用来回看「我们是怎么走到今天的」。

4.5 主页

见下一节（个人主页与装饰）。

4.6 我们

两张资料卡头像、昵称、星座、生日；卡上按钮：自己的「编辑资料 / 我的主页」，对方的「查看TA的主页」
在一起的日子可修改的日期，决定顶栏天数、纪念日、年鉴统计
配对码展示 6 位码，便于对方加入
统计共同记录（多少篇日记 / 多少张照片）、连续记录天数
存储方式显示「本机浏览器」或「云端同步」
界面皮肤深空 / 极简白 / 胶片暖 三选一
记忆与导出生成回忆年鉴、导出纪念日日历、导出我们的数据、解除配对、再看一次新手引导

4.7 私信

见「私信与通话」一节。

05个人主页与装饰

每个人都有自己的小主页，用来「装修」自己。自己的主页可编辑，对方的主页只读——你能看 TA 的背景和签名，但不能改。

背景板6 款预设渐变（深空 / 星云 / 胶片 / 雾粉 / 极光 / 墨金）+ 上传自己的图片（≤ 5MB，自动压缩到 1600px）。横幅上叠加细微星点
头像点击头像上传，自动压缩到 512px；未设置时显示昵称首字。头像会同步出现在今日、日记、我们页与顶栏
昵称最多 24 字，保存后各处立即更新
个性签名最多 40 字，显示在昵称下方，加「」引号呈现
统计卡写过的日记数、照片数、记录天数、最近心情
最近记录最近 5 条，显示日期、心情、标题或正文摘要、照片数
编辑入口两处：顶栏「主页」→「编辑资料」/「✦ 装饰背景」；「我们」页自己资料卡上的「编辑资料」
对方主页「我们」页点对方资料卡或「查看TA的主页」，以浮层只读展示，可关闭返回
依赖：云端保存头像与背景需要 lm_users.avatar、lm_users.deco 两个字段和数据库函数 lm_update_profile（见第 12 节）。未执行时浏览不受影响，保存会提示。

06私信与通话

6.1 私信

消息类型文字、图片、文件、语音留言；另有系统信号消息（通话用），不在聊天记录里显示为普通消息
图片≤ 20MB；云端上传到 Storage 后发送链接
文件扩展名白名单（图片/音频/视频/PDF/Office/压缩包/文本等）；云端 ≤ 15MB，本地模式 ≤ 2MB
语音留言点麦克风开始录音，再点一下发送；最长 60 秒自动停止；录制中显示计时与取消；气泡显示「语音留言 · 0:07」并可直接播放
未读提示顶栏「私信」标签红点；进入私信自动标记已读
刷新云端模式约每 20 秒自动拉取新消息；发送即时生效

6.2 语音 / 视频通话

  • 基于 WebRTC，点对点通话；信令写入 lm_messages 表（kind = signal）。
  • 入口：私信页「☎ 语音」按钮，以及视频通话入口。
  • 要求：双方都在云端模式、对方已加入空间、私信表已建好；否则按钮禁用并给出对应提示。
  • 通话浮层：远端画面、本地小窗、对方头像与昵称、状态文字（呼叫中/通话中/对方正在通话中）、计时、接听/静音/挂断。

07记忆产物

7.1 回忆年鉴

「我们」页点「生成回忆年鉴」，用 canvas 现场绘制一张 1080 × 1350 的图片卡片：深空渐变底、随机星点、描边框、英文等宽小标、中文正文，内容包括当年年份、在一起的年数与天数、日记数、照片数、最常心情、最活跃月份、记录最多的人、一句收尾引语。

  • 可重新生成（换一批星点与统计），可下载 PNG 保存或分享。
  • 纯本地绘制，不上传服务器。

7.2 纪念日日历（.ics）

「我们」页点「导出纪念日日历」，下载 我们的纪念日-配对码.ics，导入手机/电脑日历后长期有效：

在一起纪念日以「在一起的日子」为起点，每年重复（RRULE:FREQ=YEARLY）
数字节点第 100 / 520 / 1000 / 1314 天，单次提醒
生日双方生日，各每年重复
兼容UID 稳定（重复导入不会产生重复条目）；全天事件（VALUE=DATE）；UTF-8 + CRLF 标准格式

7.3 数据导出（JSON）

「我们」页点「导出我们的数据」，下载一份完整备份，包含：空间信息（配对码、在一起的日子）、成员资料（不含密码）、全部日记、全部私信、照片链接清单。

08数据与同步

8.1 两种模式

本地模式数据只存在这台设备的浏览器（localStorage）。断网可用、零配置；换设备或清浏览器数据会丢失，需靠导出备份
云端模式数据存 Supabase，两人各自设备实时同步；照片与文件存 Storage。约 20 秒轮询一次，写入立即生效
切换代码顶部 CLOUD.enabled 控制；两种模式的数据互不相通

8.2 同步状态

云端模式顶栏显示状态点：绿色「云端已同步」；网络异常时显示红色「同步失败」，并自动重试。云端模式下若账号在后台被删除，会在下次拉取时自动退出并回到登录页。

8.3 容量与限制

日记照片单篇最多 9 张；单张 ≤ 20MB（压缩后通常远小于此）
头像≤ 20MB，压缩到 512px
背景图≤ 5MB，压缩到 1600px
私信文件白名单扩展名；云端 ≤ 15MB，本地 ≤ 2MB
语音留言单条最长 60 秒
云端额度Supabase 免费版 Storage 约 1GB，两人日常够用；免费项目 7 天完全无活动会暂停，登录后台点 Restore 即可恢复（数据不丢）

09主题、引导与离线

9.1 三套皮肤

深空（默认）深蓝黑底、青色与金色点缀，保留全部星空、地球、银河氛围层
极简白浅底深字，隐藏星空/星云/银河/颗粒/暗角等装饰层，面板改白；首页标题改深金蓝渐变；适合白天与打印式阅读
胶片暖暖褐色调，星空与地球叠加棕褐滤镜，标题奶油金渐变，整体像老胶片

切换入口在「我们」页「界面皮肤」；选择会保存在本机，并同时作用于首页与空间。

9.2 新手引导

  • 首次进入空间时出现三步引导：记录 / 相伴 / 回望，分别介绍写日记、私信与通话、年鉴与导出。
  • 可逐页「下一步」，也可跳过；完成后本机记录标记，不再自动出现。
  • 想重看：随时点「我们」页的「再看一次新手引导」。

9.3 可安装（PWA）与离线

安装支持「添加到主屏幕」，独立窗口运行；桌面与手机图标齐全
离线Service Worker 预缓存首页、样式、脚本、图标与示例图片；离线时页面可打开，图片与最近缓存的资源可见
更新策略页面导航网络优先；脚本与样式网络优先（带版本号，更新立即生效，离线回退缓存）；图片按完整地址精确命中缓存；新版本接管后自动刷新一次

10安全模型

行级安全lm_users / lm_couples / lm_entries / lm_messages 开启 RLS，匿名请求读不到数据
配对令牌每个空间有一枚 32 位随机令牌，同时写入两名成员的账号与该空间所有数据；前端用请求头 x-couple-token 发送，策略只放行令牌匹配的行
账号操作注册、登录、创建/加入/解除空间、修改个人资料均由数据库函数完成，前端不直接读写账号密码字段
密码仅存 sha256 摘要；旧账号兼容登录后自动升级
访客建议lm_feedback 开启 RLS，只允许插入，不允许读
可接受风险Storage 的 photos 桶为公开读，知道文件路径即可访问；私密性主要由配对码 + 令牌保证。若要彻底收紧，需给 Storage 增加同样的令牌策略
密钥说明前端使用的 publishable key 公开可见属于正常设计，真正的隔离靠令牌与 RLS

11技术与文件结构

index.html

首页结构、登录/注册框、空间容器、各浮层（年鉴、引导、个人资料、通话、对方主页）

style.css

深空主视觉、三套皮肤变量、空间布局、全部浮层与响应式断点

script.js

首页交互：星图绘制、纪念日、照片墙预览、留言板、背景动效；顶部 CONFIG 为演示数据

app.js

账号、空间七个页面、日记/照片/私信/通话、年鉴、ICS、导出、皮肤、引导、PWA 注册

sw.js + manifest.webmanifest

离线缓存与安装能力；缓存策略见 9.3

images/

地球三张贴图、示例照片与占位图；换图保持 2:1 等距圆柱比例

前端形态纯静态站点，无构建步骤、无后端服务；双击 index.html 也能跑（本地模式）
后端Supabase：Postgres + RLS + 数据库函数 + Storage
部署GitHub Pages，推送到 main 后约 1 分钟自动生效
兼容Chrome / Edge / Safari / Firefox 现代版本；手机端 390px 起适配，无横向溢出
版本更新样式与脚本带 ?v= 版本参数，配合 SW 网络优先策略，更新后自动生效

13已知限制

  • 照片只来自日记：相册由日记照片汇总，不能直接向相册上传独立照片。
  • 没有回复/引用：私信为纯消息流，不支持引用、表情回应、撤回。
  • 通话依赖云端：本地模式不能通话；双方都必须在线且网络可直连（极端 NAT 下可能连不通，无 TURN 中继）。
  • 解除配对不可撤销：解除后空间分离，需要重新配对；建议先导出备份。
  • 账号找回：需先在「我们」页生成恢复码；忘记密码时用恢复码自助重置。恢复码只显示一次，丢失后无法找回。
  • Storage 公开读：知道资源路径即可访问，见第 10 节。
  • 年鉴为静态图片：生成后不随数据自动更新，需要重新生成。
  • 首页数据为演示：星图、纪念日、照片墙均为示例，想知道真实数据请进空间查看。

15验收清单

按顺序执行以下检查，可确认整套系统是好的：

  1. 首页：断网刷新仍能显示；点击空白处有星落下并连线；底部导航滚动高亮正确。
  2. 账号：注册 → 拿到配对码 → 另一账号加入 → 两人看到彼此昵称与同一天数。
  3. 日记：写一篇带 3 张照片；同一天再点「写日记」进入编辑；照片出现压缩后的小图。
  4. 照片页：看到按月份分组的相册；点击可放大。
  5. 私信：发一条文字、一张图、一个文件、一段语音；红点消失；刷新后消息还在。
  6. 主页：换头像、改昵称与签名、切一个背景；刷新后仍保留（云端模式）。
  7. 对方主页：只读打开、可关闭，没有编辑按钮。
  8. 我们：改在一起的日子，顶栏天数变化；连续记录天数合理。
  9. 年鉴：生成图片，尺寸 1080 × 1350，可下载。
  10. 日历：导出 .ics，导入系统日历能看到年度重复的纪念日与生日。
  11. 导出：JSON 里能找到日记、私信与照片链接，且不含密码。
  12. 皮肤：切到极简白与胶片暖，首页与空间同时变化，文字清晰可读。
  13. 手机：390px 宽度下无横向滚动，七个标签可点，输入框可用。
  14. PWA：浏览器提示可安装，装好后独立窗口打开正常。
